# 🚀 React Admin Dashboard

A modern, responsive, and fully functional Admin Dashboard template built with **React (CRA)**, **TypeScript**, and **Bootstrap 5**.

[🔴 Live Demo](https://tunazkn-admin-dashboard.vercel.app/)

## 🛠️ Tech Stack

- **Core:** React, TypeScript, Create React App
- **Styling:** Bootstrap 5, SCSS
- **State Management:** Context API (Auth & Theme)
- **Routing:** React Router v6
- **Internationalization:** i18next (TR/EN Support)
- **Data Persistence:** LocalStorage

## ✨ Key Features

- 🌗 **Dark/Light Mode:** Seamless theme toggling.
- 🌍 **Multi-Language:** Full English and Turkish support.
- 📊 **Dashboard:** Dynamic KPI cards and inventory analysis.
- 👥 **User & Product Management:** CRUD operations with mock data.
- 🔐 **Authentication:** Simulated login flow with protected routes.
- 📱 **Responsive:** Fully mobile-friendly layout.

## 🚀 Getting Started

To run this project locally:

### 1. Clone the repository

```bash
git clone https://github.com/tunazkn/react-admin-dashboard.git
cd react-admin-dashboard
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the project

```bash
npm start
```

Runs the app in the development mode.
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
